## 🧩 About

**Palworld helpers** is a curated list of Palworld open-source tools:

- **Overlays** — on-screen helpers, layout notes, stat viewer, quick menu
- **Quality-of-Life Helpers** — inventory catalog, Pal manager, overlay notes
- **Research Notes** — base layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Quick Menu — access common actions from one overlay
- Stat Viewer — view player and Pal stats
- Time Control — adjust in-game time for study
- Movement Notes — adjust speed for exploration

### 🎨 Catalog & Cosmetics
- Pal Catalog — browse Pals, colors, and skins
- Custom Skin Notes — organize player cosmetics
- Visibility Enhancements — improved night and weather clarity

### 🏋️ Base Layout
- Base Building Notes — segment study on any layout
- Resource Viewer — track materials and items
- Crafting Notes — chain complex recipes in the editor
